# 使用手册

## 语音服务：让 AI 说话的声音

位置：**设置 → 语音服务**(Settings → Voice Services)

不配置这个时，AI 读的默认是苹果自带的播音腔。要换成别的声音，就在这儿加一条「语音服务」——选一个厂商，填它给你的东西。

### 新建一条服务

点右上 ＋ 号：

- **厂商** — 用哪家(OpenAI / Azure / MiniMax / 豆包 / ElevenLabs 等等)，选完自动填默认值
- **名称** — 你自己取的，方便区分
- **接口地址** — 厂商给的 API 地址，默认已填好，一般不动
- **API 密钥** — 厂商给你的 sk-xxx,**只存在你本机的钥匙串里**
- **模型** — 厂商的 TTS 模型 id
- **音色 ID** — **最重要的一项**。厂商控制台里每个声音有个名字，比如 Azure 的 `zh-CN-XiaoxiaoNeural` 是晓晓(中文甜妹)，MiniMax 的 `female-shaonv` 是少女感。**复制粘贴到这里就能换掉声音**

### 调参数(每家有不同)

编辑器往下滚：
- **语速** / **音量** / **音调** — 大多数厂商自带
- **情绪** — MiniMax 专属(happy / sad / angry)
- **指令** — OpenAI 专属，用话术调语气(比如「温柔一点的说」「跟轻声说的一样」)

**留空 = 厂商默认值**。

编辑器里的「播放试听句」按钮，就是用你刚填的东西合成一段试听——**没保存的密钥也行**。

### 列表页

加完回到列表，一行一条服务。

- **点行** — 选这条作为既有声音
- **喇叭键** — 直接试听，不用进编辑器
- **齿轮** — 编辑
- **左滑** — 删除

### 朗读行为

- **换声音立刻重读** — 正在读的立刻停，没读到的以新音色重读
- **厂商出错自动降级** — 挂了/没钱/key 错，自动换下一个启用的服务；还不行就差到本机系统声音
- **浮窗标签** — 气泡上那个胶囊,名字会显示现在用的是哪条服务

### 系统语音的齿轮

列表第一行的「系统语音(Apple)」。本机声音可调了：点齿轮可以选**音色**、**语速**、**音调**、**音量**——原本藏在更深处的东西现在都在这里。

### AI 发语音(语音气泡模式)

编辑栏的 **••• 菜单**里有个「AI 语音回复」(AI Voice Replies)开关——**每个会话各管各的**。

开了之后，AI 每条回复除了文字，末尾会多一个**微信式语音气泡**：小喇叭+跳动的声波+秒数。气泡里的声音就是你配置的语音服务(上面的列表选中的那条)。

- **自动播放** — 回复完成气泡落下来就播，不用点
- **暂停/继续** — 气泡下编辑栏的 ▶ 播放键：播放中按=暂停，暂停中按=继续
- **点气泡本体** — 打开全屏播放器，拖进度条
- **语音进语音出** — 你用语音发消息(麦克风说)，这个开关自动帮你开上；打字发的不会

**声音不是我选的吗？** 气泡用的就是你「语音服务」列表里选中的那条。要换声音：设置 → 语音服务 → 点别的服务行，立刻生效。

**合成失败**（服务没配好/没 key）会有 toast 提醒，不是静默没声。

## 朗读：消息怎么读

每条 AI 回复的**气泡底下**，一排小图标：

- **播放(▶) / 暂停(⏸) / 继续** — 朗读这条气泡的文字（只读这条，不读全文）；点播放会自动打开朗读开关
- **重新回复(↻)** — 从这条前面的问题重新生成一次回答
- **复制(⧉)** — 复制这条的文字
- **删除消息(🗑)** — 删除有确认框：**这条和它后面的所有消息会一起删**（这是数据安全的删法，单独抠掉中间一条会让上下文错位）

流式输出中操作条自动隐藏，回复完才出现。

**只想读某一句** — 长按选中那段文字，选「朗读所选」。

**浮窗胶囊** 还在：暂停/继续、静音(只听不播)、读什么(全文/只读引号/跳过括号)、语速(1.0–2.0 循环，聊天外朗读也能调)、关闭(×)。

## AI 主题：它长得不一样

位置：**设置 → 外观 → AI 主题包**(Settings → Appearance → AI Theme Pack)

GitHub 上的 .json 主题包可以改掉 AI 那部分消息的配色。一个包能调的：

- 文字颜色、背景颜色、圆角
- 工具结果的底色/边框
- 代码块的底色
- markdown 分割线的颜色
- 成功/警告/错误的专属颜色

**气泡透明度** 下面的滑杆，0.15 到 1 全程调。

## API 配置：该用哪个模型

位置：**设置 → 模型组**(Settings → Model Groups)

模型组这个设计：几条模型绑为一组，**前一个报错了自动换下一个**。

- **Default Primary** — 主对话组的
- **Default Sub** — 轻任务(起名/摘要)用的组
- **Voice Input** — 语音识别组
- **Voice Output** — 语音合成组
- **Vision Input** — 图片识别组
- **Agent Loop Models** — Agent 循环调用的组

每组里面对应具体的 MiniMax、豆包、等模型条目。多模型容错，单独有问题就再加一条，不用改结构设计。

## Provider 接进来怎么调

位置：**设置 → Providers**(Settings → Providers)

这是 API 入口的地方。一条 Provider = 一个上游服务。

### 新建 Provider

点右上 ＋：选一个类型(OpenAI / Anthropic / Gemini / Antigravity 等)，填：
- **名称** — 自己取
- **接口地址** — 上游 URL
- **密钥** — sk-xxx / anthrop key / gem key
- **保存**

填完这条就算接通了，但还没模型能用——**要进详情页加模型条目**。

### 加模型条目

进 Provider 详情页 → 拉到「模型列表」一栏 → 加一条：
- **模型 ID** — 跟上游文档一致，比如 `gpt-4o` / `claude-opus-4-1` / `deepseek-chat`
- **显示名** — 在模型组里看到的标签
- **上下文窗口 / 最大输出** — 填了才精确，不填走默认

加完这个模型才会出现在模型组下拉里，能在对话里选。

### Thinking（推理思考）怎么开

**不是所有模型都支持 thinking**。开法分三层：

1. **模型自带支持** — 上游声明了这个模型能 thinking，详情页「Thinking」开关自动是开的，不用管
2. **手动强开** — 模型其实支持但上游没声明，点「Force Enable Thinking」硬塞（注意：模型不认的话会报错，退掉就行）
3. **Thinking 规则** — 详情页下面的规则列表。每条规则 = 「这个模型 id 该用什么 thinking 字段格式发」

规则长这样：

- **匹配范围** — 全部模型 / 模型 id 匹配模式（`deepseek-*` 这种）
- **发什么** — `reasoning_effort` / `enable_thinking` / DeepSeek 的 `thinking`+`reasoning_effort` 兄弟写法 / Qwen 的双发 / 什么都不发（Mistral 那种禁的）
- **不匹配就走下一条**，最后兜底

为什么这么复杂？每家厂商、每个反代，thinking 字段怎么发都不一样，发错了不是少思考是直接 400 报错。内置了 17 条规则覆盖主流厂商，够了就用；不够自己加一条 custom，**custom 排在所有内置之前**，加完立刻生效。

### Tool（工具调用）怎么开

**tool = 模型能不能调外部工具**（搜网页、跑代码、读文件那种）。

- **模型支持 → 自动开** — 上游声明了 supportsTools，对话里自动出工具按钮
- **没声明** — 不能强开。换一个支持 tool 的模型（GPT-4o / Claude / DeepSeek-V3 都支持）
- **DeepSeek-V3 / Qwen 之类** — 开了 thinking 之后 tool 字段会变（DeepSeek-V4 要 `thinking.type:enabled` + `reasoning_effort:high` 兄弟发；Qwen 要 `enable_thinking` + `thinking_budget` 双发且 budget 必须小于 max_completion_tokens）

**报错看哪层：**
- `400 extra_forbidden`（Mistral 风格）→ thinking 关掉，这个上游禁 thinking 字段
- `400 UNKNOWN_FIELD` → thinking_budget 这字段这个反代不认，换裸 `enable_thinking`
- `Reasoning is mandatory for this endpoint` → 这模型思考是强制的，关不掉，就让它跑

### 余额 / 429 / 风控

- **429（Rate Limit）** — 同模型自动退避重试（首次尊重 Retry-After 头），不是立刻换模型
- **余额不足**（insufficient balance / 余额不足）— 死错，立刻停不浪费轮次
- **走完退避还是 429** → 换模型组里下一个
- **上游挂了** → 自动降级到下一个 Provider 的同模型

中转预扣费（按 input + max_tokens）是真坑：对话框里 max_output_tokens 填太大，中转预扣你账上没有的钱直接拒。不设 max_output_tokens 字段不发，就不炸。

### 测试 Provider 是否通

详情页 → 「Test Connection」按钮，发一个 ping 请求看返回。
**记住：测一次就行，别反复测，上游会风控。**

## 其他的小东西

### 浮窗胶囊
气泡上方右下角那个转圈的小胶囊。它在读的时候显示的就是 Activity：
- **暂停/继续** — 点巨暂停/点继续
- **静音** — 只听不播(喇叭变灰)
- **朗读内容** — 全文 / 只读引号 / 跳过括号
- **语速** — 播放语速 1.0–2.0 循环
- **关闭 ×** — 完全关掉朗读

### 过期了的旧设置
设置 → 背景增强里的「语音」滑杆现在已经不作效——系统语音的调音现在在「语音服务清单里点齿轮」了。

### 长按菜单
长按任何 AI 消息还能看到旧菜单：
- 「\u8bfb selected」朗读所选
- 「Read from Start」朗读整张
- 「Copy All」全部复制
- 「Copy Markdown」复制 markdown
- 「Compact Above」从这条起往后压缩上下文

## 最近多的东西

- **语音服务** — AI 终于能用自己的声音读了，不再固定在苹果默认上
- **AI 语音回复(语音气泡)** — AI 的回复自带微信式语音气泡，自动播、可暂停继续；你说话发消息它自动开
- **消息气泡下的操作键** — 复制 / 播放 / 暂停 / 停止一排直接在气泡底下，不用点长按菜单了
- **换声音立刻重读** — 不用呆呆等旧声音读完
- **浮窗暂停键** — 之前只有静音，现在有真正的暂停

## 技能(Skills)：教 AI 怎么做某件事

位置：**设置 → 技能**(Settings → Skills)

技能 = 一段说明书，AI 在该用它的时候自己读。不是一直加载的，是触发式——你跟它说「搜一下」「整理一下」，它去翻对应的技能。

- **内置技能** — 装好了的，开关一下就用
- **导入技能** — 支持从文件夹/外部导入 SKILL.md
- **技能做的是**：给 AI 一段上下文 + 几个操作步骤，它按这个走

**技能 ≠ 角色卡**。角色卡管它「是谁」，技能管它「遇到这件事怎么做」。

## MCP：外接工具箱

位置：**设置 → MCP**(Settings → MCP)

MCP = 给 AI 外接的工具包。装一个 MCP server，AI 就多一组能力：搜全 GitHub 的代码、查库文档、问任意仓库、连 Gmail/云盘（Zapier）、加密货币行情、计算引擎……

- **装** — 设置里加 server（URL/命令），或从社区配置导入
- **用** — 不用指挥，AI 遇到对应的活自己会调；你说"帮我查XX"它就走搜索类
- **看有什么** — 直接问 AI"你手上有什么 MCP"即可

## 快捷指令：隔空派活

系统快捷指令 App 里能找到 我的小家 的一组动作：**发送 Prompt / 追问 / 打开会话 / 列会话 / 重试** 等。

- **自动化定时唤醒**：快捷指令 → 自动化 → 特定时间 → 「发送 Prompt」（内容写任务）——到点 AI 自己被叫醒干活。这是让 AI"每天固定做某事"的唯一可靠方式
- **Siri**：对着 Siri 说这些动作名也能触发

## 外部文件夹：挂进来读

位置：**设置 → 外部文件夹**(Settings → External Folders)

iOS Files 里的文件夹可以挂进来看（Obsidian vault / Downloads / 别的 App 的 iCloud 容器都行）。

- **挂载后** — 在 App 里浏览、读、（看权限）写
- **有些只读** — 看源 App 给不给写权限，不给就只能看
- **文件预览** — 点进去：图片直接看、markdown 渲染、PDF/Office 走系统 QuickLook、代码高亮

## iCloud 同步：换机不丢

位置：**设置 → iCloud 同步**(Settings → iCloud Sync)

- **同步什么** — 会话记录、设置、技能、记忆。**不同步 Provider 密钥**（钥匙串的，Apple 不让跨设备带过去）
- **换机** — 新机登同个 Apple ID → 打开 iCloud → 拉下来
- **推到云端** — 「Force Sync」强制推一次（默认是改动后自动推）
- **冲突** — 以云端为准覆盖本地（单向，不是双向合并）

## Soul：它的人格

位置：**设置 → Soul**(Settings → Soul)

Soul 是这个 AI 的人格设定文件——它是谁、怎么说话、什么能做什么不能做。

- **编辑** — 直接改文字保存就生效（编辑器有字符上限显示，超了会提示）
- **生效** — 保存后下一个对话轮次就用新的
- **备份** — 改之前可以复制一份留着，改坏了能恢复

**Soul ≠ 记忆**。Soul 是出厂设定的「我是什么」，记忆是「我们聊过什么」。

---

## 记忆：它记得什么

位置：**设置 → 记忆**(Settings → Memory)

- **Daily 日志** — 按天的流水，每天一个文件
- **GLOBAL** — 全局常驻设定，每次都读
- **搜索** — 顶上搜索框，按关键词模糊找
- **会话之间** — 不删的记忆跨会话留着；删了等于它从头学

## 环境变量：API key 不想写死在 Provider 里

位置：**设置 → 环境变量**(Settings → Environment Variables)

- 把密钥存在环境变量里，Provider 密钥栏填 `$$VAR_NAME` 引用它
- 换 key 不用进每个 Provider 改，改一处环境变量就行
- **不会出现在对话里**——AI 看不见环境变量的值

## 终端：App 里的 Linux shell

位置：**设置 → Shell Terminal**(Settings → Shell Terminal)

App 里跑了个完整的 Alpine Linux（iSH）。这是整个 App 里上限最高的东西——能干的事远不止"看看"。

### 里面有什么
- **现成的**：python3(3.12)、pip、git、curl、wget、ssh、jq、ffmpeg——能写脚本、拉代码、调接口、转音视频格式、连服务器
- **能装的**：`apk add <包名>` 随时装（装不了的大东西说明 rootfs 空间有限）
- **文件共享**：终端里的 `/var/minis/` 就是 App 的数据区——`attachments/` 是你发进对话的文件、`workspace/` 是 AI 的工作区、`shared/` 是跨会话存储。**AI 和终端看得到同一份文件**：你在对话里发图，AI 从 attachments 读；AI 写个网页到 workspace，给你一个 `minis://workspace/...` 链接点开就是

### 能玩什么（举真实的例子）
- 让 AI 写个 HTML 小工具/看板 → 落在 workspace → 对话里点链接直接用，还能收藏
- 丢给它一批文件（图片/CSV/文档）→ 它用 python 处理完把产物放回 workspace 给你下载
- `ssh` 连你自己的服务器 → 在手机上管机器；AI 也能帮你跑运维命令
- ffmpeg 转音频格式、抽视频音轨
- 写 python 处理文本/算东西/画图表，结果转成图片发进对话

### 和 AI 配合的正确姿势
- **要产物**：直接说"帮我做个XX"，AI 写完给链接，点开即用
- **要交互**：需要输密码/登 SSH 的活，AI 会给你一个 [打开终端](minis://open_terminal) 链接，你自己进去敲
- **定时活**：iOS 快捷指令 App → 自动化 → 设时间 → "发送 Prompt 给 我的小家"，AI 会定时被唤醒干活（比如每天的固定任务）。这是唯一可靠的定时方式，App 挂起时内部定时器会停

### 注意
- **rootfs Management** 管终端的磁盘，快满了会提醒
- 终端里 `rm` 是真的删，没回收站
- 环境变量页（Settings → Environment Variables）存 key，终端和 AI 都能用 `$名字` 引用，值不会出现在对话里

### 深链
- `minis://open_terminal` — 直接开终端（对话里发这个链接就能点）
- `minis://settings/...` — 直达某个设置页
